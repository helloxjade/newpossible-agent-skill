- README 超过 500 字，并包含作品特点、核心亮点、实现方案、架构、部署、大模型优化、Agent Skills 和技术栈。
- 仓库包含 `skills/newpossible-tech-scout/SKILL.md`。
- `.env`、API Key、密码、运行时临时文件和本机路径没有进入提交。
- 最新一次 `npm test` 和 `npm run validate:skill` 通过。
- GX10 真实实验结论已在页面和演示视频中展示。
- README 中的截图、视频和仓库链接在无登录状态下可访问。
